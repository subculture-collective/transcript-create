03 / A FEW THINGS TO KNOW

Who is Rekolekt for?

Creators maintaining a back catalog, researchers working with recorded conversations, and communities building a shared reference. It is software you can run for your own archive.

Can I run it myself?

Yes. Rekolekt is open source under Apache 2.0. It uses React, FastAPI, PostgreSQL, and transcription workers. Start with the development guide and client deployment guide. Features depend on your server configuration.

What does a passage link preserve?

A passage link returns to a selected range in the currently available recording and transcript. It is not an immutable citation or a downloaded video clip. Automated transcripts can contain errors; check the recording before quoting.
