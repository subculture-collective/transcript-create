# Accessibility

**Status:** shipped baseline (2026-07-12).

Transcript Archive targets WCAG 2.2 AA. Routes use one main landmark, labelled controls, 44 px targets, keyboard-operable menus and tabs, Escape and focus restoration, reduced-motion styles, explicit loading, error and empty states, and accessible tables beside visual timelines. Transcript layout controls expose pressed state and timestamp evidence links remain keyboard reachable.

Axe coverage includes Layout, Search, Explore, Saved, Topic, and Video states. Seeded browser checks cover mobile navigation and intelligence flows. PWA installation and offline behavior are intentionally unsupported.

New views must include keyboard, mobile, reduced-motion, loading, empty, unavailable/degraded, error, and correction states where applicable.
